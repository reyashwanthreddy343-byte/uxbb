# Light theme refresh

## Goal
Apply the selected polished light direction without changing the Run page structure or behavior.

## Changes
- Replace the dark-first color tokens with crisp white and neutral-gray surfaces.
- Use a clear blue primary color, with accessible green, amber, and red status colors.
- Soften borders, inputs, side panels, the replay canvas grid, and shadows for daylight readability.
- Update replay cursor and target overlays to use the shared theme colors.
- Preserve the existing monospace accents, compact controls, responsive layout, and all live-run functionality.

## Verification
- Check the Run page at desktop and mobile widths.
- Confirm text, fields, controls, findings, and replay overlays remain readable and aligned.
